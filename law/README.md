# law/

The encoding of the law: one folder per toeslag plus `awir/` for the shared rules, each
with `rules.md`, dated `parameters/<year>.yaml`, the executable rules and generated
tests, and `CHANGES.md` for every amendment. The layout, the rule format, the status
ladder (`draft` → `tested` → `reviewed` → `established`) and the source hierarchy are
defined in [`LAW.md`](../LAW.md). Every number here cites its article (`CHARTER.md` P1).
