**Lessons.** A ruling's component figures can contradict its own total (ECLI:NL:RBZWB:2018:2319: € 15.070 + € 16.604 against '€ 30.674' and '€ 30.670'): compute the Dienst's amount under each figure, take the one it fits, write the others and the reason in the case, and flag it first in Ask 9 (10-29). An outcome that depends on an input the ruling does not state (a partner's verzekering under art. 2 lid 5 oud, a verblijfsstatus, a change within the year) is neither a case nor a discrepancy — write it in `SOURCES.md` §4 with the text's figure beside the Dienst's, so a full read can settle it (10-29, ECLI:NL:RVS:2017:3139). A voorschot that equals the year's maximum at an unstated income is still no case; the same maximum at a *stated* income below the drempel is (10-29). A ruling can misname the year of a beschikking (ECLI:NL:RBOBR:2025:1536 calls a 2020 voorschot 'voorschot zorgtoeslag 2021'): settle the year from the ruling's own figures (the terugvordering equalled that voorschot plus rente; the amount is the 2020 text's to the euro and not the 2021 text's) and from its scope, write the reasons in the case, and say it is the operator's reading for the verifier to test (10-28). A computation the Dienst itself calls a mistake (a voorschot without the woonlandfactor) is still a Dienst outcome for the inputs it used: store it with those inputs and say what the Dienst said about it; the corrected outcome is a case only if its inputs are stated (10-28: the country was anonymised, so it is not). Playwright in this environment is the node package (`require('playwright')`), not the Python one; the Chromium path memory gave (`chromium-1194`) no longer exists — `chromium.launch()` from node needs no path (10-28). A ruling's amount that the text does not give is logged `open`, not explained away: #11 (10-27) was tempting to attribute to provisional parameters — written as 'to investigate' instead. A rechtbank's 'geschat jaarinkomen' can be the inspecteur's registered figure later corrected (ECLI:NL:RBNHO:2024:2245): quote the word, say what it was. A sweep script that appends to a file must be idempotent (`done` set) because the Bash call may be cut off. `tools/render.py` was CRLF until 10-26 and is LF now; before rewriting any source file with a script, run `file` on it and preserve its endings, or the diff hides the change (10-26).
