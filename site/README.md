# site/

The checker: a static site, built from `law/` and `cases/`, that runs entirely in the
citizen's browser and shows every step of a computation with the article beside it.
Plain Dutch at B1, phone first, WCAG 2.2 AA, nothing to sell, nothing leaves the device.
The binding rules are in [`DESIGN.md`](../DESIGN.md); the result page follows layout B,
*het verhaal*, chosen by the owner on 2026-10-09 (Ask 3). Licence: MIT ([`LICENSE`](../LICENSE)).

Files:

- `index.html` — the front page (generated by `tools/build.py build`).
- `zorgtoeslag.html` — the checker: input form and result page, 2024–2026 (generated from
  `tools/zorgtoeslag.template.html`).
- `zorgtoeslag-regels.js` — the rules in the browser: a line-by-line port of
  `law/zorgtoeslag/rules.py` with the same rule ids, exact BigInt arithmetic. Source, not generated.
  `tools/build.py check` runs every case through both and fails if they differ.
- `zorgtoeslag-parameters.js` — every parameter file under `law/` as one object, with each
  number's article (generated; the yaml files are the source).
- `layouts/` — the three layouts shown for Ask 3 (A de tabel, B het verhaal, C de brief), kept
  as the record of the choice.

Not yet published anywhere: the files work when opened from a checkout. Publishing is Ask 7.
